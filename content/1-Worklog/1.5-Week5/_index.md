### Week 5 Objectives:

* Support the deployment of the first AWS services in the system.
* Build appropriate IAM roles for service-to-service interaction.
* Establish system observability using Amazon CloudWatch.
* Review logs across ingestion, processing, and backend components.
* Manage log retention to avoid unnecessary costs.

### Outcomes This Week:

* Enabled AWS services to interact without hard-coded access keys.
* Collected logs that support troubleshooting in the input pipeline.
* Made it possible to monitor data processing and API behavior.
* Learned how to query and filter error events with Logs Insights.
* Built a centralized view for important logs and metrics.
* Reduced the risk of unnecessary costs from unlimited log retention.
